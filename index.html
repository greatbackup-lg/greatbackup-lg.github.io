greatbackup-lg Backup

greatbackup-lg Backup is a personal backup tool used by a single person. It is not offered to the public and has no other users.

What it does

The tool runs on the owner's own computer. It uses the open-source programs rclone and restic to copy encrypted backup files from that computer into a folder in the owner's own Google Drive, and to read those files back when a restore is needed.

How it uses Google data

  • It requests only one Google permission: https://www.googleapis.com/auth/drive.file. This lets the tool see and manage only the files it created itself. It cannot see any other file in Google Drive.
  • Backup files are encrypted on the owner's computer before upload. The tool does not read, analyze, or share their contents.
  • No data is sent to any server other than Google Drive. There is no website account, no tracking, no advertising, and no analytics.
