Privacy Policy

App: greatbackup-lg Backup
Effective date: October 21, 2026

1. Who uses this app

This app is a personal backup tool used only by its owner. It is not offered to anyone else.

2. What Google data the app accesses

The app requests a single Google OAuth scope: https://www.googleapis.com/auth/drive.file. With this scope the app can access only the Google Drive files that the app itself created (encrypted backup files). It cannot access any other file, email, contact, or account information.

3. How the data is used

The app uses this access only to upload encrypted backup files to the owner's Google Drive, list them, and download them for restore. Files are encrypted on the owner's computer before upload.

4. Storage and sharing

Backup files are stored only in the owner's own Google Drive. The OAuth token is stored only on the owner's computer. The app does not send Google user data to any other server and does not sell, share, or transfer it to any third party. The app does not use Google user data for advertising, analytics, or training of any model.

5. Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Backup files can be deleted directly in Google Drive.

7. Contact

Questions: github.com/greatbackup-lg
